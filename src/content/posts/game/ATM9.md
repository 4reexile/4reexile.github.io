# ATM9

我看水槽包也是风韵犹存啊, 纯文字无图

## 寄巧

1. 黑盒+坞, 前期就能拿到的非常大存储用于挖矿
2. 复仇之镐自带时运5, 且可以将镐子和书扔到地上, 让铁砧放在上方掉下来砸一下就能获取时运5
3. 红图可以复制机器的配置, 应该是热力膨胀的吧
4. 纠缠方块, 维度储罐, 维度箱子都可以跨纬度传输, 还有我们的ae量子环
5. 自动合成机, 第一个:INT 最后一个:ExtC,只会输出最终产物, 用于下级精华合成终极精华
6. 前期烧矿使用机械动力鼓风机, 和动力没有关系, 处理最快的时候是当物品16个为一组输入

## AE

1. 逃课之村民交易: 充能器 -> 福鲁伊克斯水晶
2. AE系统最少需要: ME控制器 + ME驱动器 + ME样板编码终端 + ME合成终端
3. 自动合成需要: 样板供应器/ME扩展样板供应器 + 合成存储器
4. 粗线缆可以接32台机器, 细线缆最多8台, 可以从粗线缆1分4

### 无线AE

1. 想要随时随地开ae终端? 无线合成终端 + 无线访问点 + 无限范围增幅器(维度卡), 或者直接用量子环, 纠缠态奇点一个放在量子环一个放在你的终端
2. 多个无线终端可以通过合成拼在一起, 左边栏有切换功能
3. 喜欢玩无线AE需要: ME无线连接工具, ME无线连接器

你已经学会了几乎所有的ae知识,快去搭建自动化产线吧!

## mek

前期完全可以通过这一个模组进行快速发展, 核电轻而易举

### 灌注合金自动化

1. 利用基础冶金灌注机将红石变回化学品, 物品输入配置记得选择额外(输入到那个黄色槽中)
2. 灌注类型配置对着管道的选择输出, 就能拿到化学品红石(用的加压管道)
3. 此时就可以让灌注工厂同一个面输入铁锭和化学品红石让它自动工作了

ME化学品存储磁盘

## 热力膨胀

1. 热力灌注机之类的可以不要循环模块，在顶上设定为输入输出再加一个ME接口即可(至少要在ME接口标记水)
2. 热力灌注机器加神秘农业种子是资源获取的重要方式

## 通量网络

1. 通量网络控制器, 第三个模块是无线充能, 开启之后就会消耗网络内电力给选定的格子充电

## 刷怪笼

1. 查询jei有更详细的部分, 给刷怪笼喂东西会有不同的效果

```
金苹果: 无ai
灵魂灯笼: 忽略光照
龙蛋: 忽略环境
```

2. 怪物蛋获取:

棉签右键生物获取DNA, 地漏经验奇异储罐站上去获取流体经验桶; 流体经验桶,DNA再加上种子就是小鸡饲料(忘了,反正大概就这样), 喂给鸡就有对应的怪物蛋, 用于刷怪笼刷怪

你甚至可以获取boss的刷怪蛋然后无ai, 通过工业先锋屠宰场秒杀

## power

1. atm9有纠缠方块,可以纠缠充能台, 物品输入输出好看一点
2. 尽管搭建, 我搭建的是`7*7*7`的充能棒方块
3. 我喜欢power的热力发电机, 只需要底下有热源方块之消耗水就能获取能量, 有不错的收益, 直接堆量

## 深度学习

1. 一共就需要这些: 战利品制造器 + 模拟室 + 空白数据模型 + 深度学习器
2. 数据模型右键坚守者塞进深度学习器, 打六次就行
3. 做点预测矩阵塞进模拟室, 就能产出预测产物, 塞进战利品制造器制造战利品

## 如何无敌

1. 首先要一个药师研钵
2. 通过放入 铁锭 + 钻石->抗性提升Ⅱ 获取药水精华
3. 药水精华 + 钻石可以继续提升, 直到抗性Ⅴ, 你快无敌了
4. 然后需要一个药师坩埚
5. 放入 一桶水 + 药水精华 + 下界疣 + 红石
6. 用浓缩药水瓶装, 喝下药水拿着药水卡对空气右击, 显示激活即可
7. jei查看灌注塔, 插入药水卡就可以永久抗性Ⅴ

## 植物魔法

1. 产能前面直接烧煤炭得了, 最基础的植物
2. 后面使用凋零菟葵, 花格箱自动漏下去(机械动力应该更好)
3. 自动化我记得也是花格箱漏下去, 路由器点击合成, ae配置直到主产物返回

## 路由器

1. 真空模块 + 范围升级拓展用来大范围吸收掉落物, 应该有更好的替代
2. 一个路由器放原矿, 一个路由器用时运镐子挖矿, 会掉一大堆
3. 还有什么移动物品, 挖掘方块, 右键点击之类的功能用于自动化, 非常好用(比如植物魔法的仪式)
